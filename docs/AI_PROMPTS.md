# AI Prompts Used During Development

This document records the types of prompts used during the development of the Airbnb clone. AI was used selectively as a development assistant for guidance, debugging, UI refinement, and targeted implementation support. The generated suggestions were reviewed, modified where necessary, and tested in the project before being integrated.

## 1. Project Planning and Implementation Guidance

Example prompts used:

- "How should I structure a React + TypeScript Airbnb listing page with reusable components?"
- "Suggest a clean component structure for the listing page, photo tour, and lightbox."
- "What is a suitable folder structure for a React frontend and Node/Express backend for this project?"

## 2. Backend and API Assistance

Example prompts used:

- "Help me debug this Express/Mongoose API issue."
- "How should I structure the listing schema and API response for this Airbnb-style listing?"
- "Why is my MongoDB/Mongoose validation failing for this field?"
- "Help me fix this backend error without changing the overall project structure."

## 3. Frontend UI and CSS Refinement

Example prompts used:

- "Help me match this section's spacing, sizing, and alignment more closely to the reference."
- "Why are these cards appearing in two rows instead of one horizontal scrollable row?"
- "Help me make this navigation bar appear only after scrolling past the photo section."
- "Adjust this CSS so the content width and spacing match the reference layout."

## 4. Photo Tour and Lightbox

Example prompts used:

- "Help me implement navigation between photos in a React lightbox."
- "How can I add keyboard navigation with ArrowLeft, ArrowRight, and Escape?"
- "Help me implement focus handling and prevent background scrolling while the lightbox is open."

## 5. Debugging and Build Errors

Example prompts used:

- "Explain this TypeScript build error and show the smallest change needed to fix it."
- "Why is this import reported as unused?"
- "Help me identify why this component is not displaying correctly."
- "Review this error and suggest a targeted fix without rewriting unrelated code."

## 6. Documentation and Submission Preparation

Example prompts used:

- "What should be included in the README for this take-home project?"
- "Help me create a simple architecture diagram based only on the technologies actually implemented."
- "What files should I remove before creating the final submission ZIP?"
- "Help me document AI assistance honestly without implying that AI built the entire project."

## Development Approach

The general workflow was:

1. Implement the feature manually.
2. Run the application and identify issues.
3. Use AI for targeted guidance or debugging when needed.
4. Review the suggested solution.
5. Modify or integrate the relevant code.
6. Run/test the feature again.
7. Continue with the next feature.

AI was therefore used as a coding and problem-solving assistant rather than as a replacement for the development process.
